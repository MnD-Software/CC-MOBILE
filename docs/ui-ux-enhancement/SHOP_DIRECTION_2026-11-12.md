# Shop direction — 12 November 2026

The owner rejected the full-width Shop redesign and requested the earlier category-first layout, using Oraimo and Carrefour as design references. The previous Shop screen has been restored from the source before the 11 November redesign: a persistent left category rail with imagery and selected-state styling, the product grid to its right, and the existing filter/subcategory controls.

Predictive search, pagination, sorting, budget filters, category sheets, image loading, favourites, checkout and the recent backend fixes remain available. Search results retain their previous full-width behavior when a search is active. Later account, tracking and navigation fixes are unchanged.

This correction restores the owner's established screen; it does not claim a pixel-exact recreation of either reference app. Future Shop layout changes should preserve this category-sidebar direction unless the owner requests a different arrangement.
