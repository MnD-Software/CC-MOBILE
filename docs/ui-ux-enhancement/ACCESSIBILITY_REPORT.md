# Accessibility

Existing shared controls retain semantic roles, loading/disabled states, labels, reduced-motion handling and safe-area support. Product names no longer clip after two lines. Shared buttons accommodate two centred text lines and minimum touch sizing; dashboard action rows wrap and stretch. GPS permission is requested only after the rider opts in, and permission failure does not block proof-of-delivery entry.

Local automated checks cover shared button announcements and disclosure states. Browser responsive checks are recorded separately. VoiceOver/TalkBack, physical-device font scaling, native map focus, large accessibility text, contrast across every screen and native keyboard/safe-area acceptance remain unverified. No complete accessibility certification is claimed.
