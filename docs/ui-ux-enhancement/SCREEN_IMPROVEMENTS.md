# Screen improvements

**12 November correction:** Shop now uses its restored category sidebar and product grid, following the owner's Oraimo/Carrefour reference direction. The full-width redesign described below has been reverted. See [current Shop direction](SHOP_DIRECTION_2026-11-12.md).

- **Notifications:** each order update now shows its order reference, making updates for multiple simultaneous purchases distinguishable. The browser check opens the exact notification identity rather than matching a shared title.

- **Shop:** removed the fixed category rail; categories remain available in the existing sheet. Products gain the released width, with fewer stacked controls in the All view and more row spacing.
- **Product cards:** 15-pixel names, 22-pixel line height for grid cards, natural wrapping and subtle elevation. Real images, price logic, favourites and quick-add behavior are preserved.
- **Home/Product:** concierge entry hidden; recently viewed only records a visible matching product route. One-time migration clears contaminated viewing history while preserving other preferences.
- **Orders/Tracking:** plum hero, stage timeline, rider milestones, private GPS map, contact action and disclosed receipt/details. Current status comes from backend records.
- **Rider/Dispatch:** explicit foreground GPS sharing, proof required for completion, terminal trips disclosed separately, safer query loading and revision recovery.
- **Web operations:** real production-location assignment and rider-account allocation replace contact-only assignment. Handover, transit, proof and exceptions use logistics tasks.
- **Navigation/buttons:** one active tab; wrapping, aligned shared buttons. Existing account-recovery work is preserved.

Club membership-card redesign, broader Account restructuring, corporate capabilities and extensive native visual acceptance are not represented as completed in this increment.
